# VaultCore

A simple banking database project created with MariaDB.

This project includes:

- Customers
- Accounts
- Account types
- Transactions
- Audit logs
- Foreign keys
- Indexes
- Stored procedure
- Trigger

The project is mainly created for practicing SQL and understanding database relationships.

## Run

Import the SQL file into MariaDB:

```bash
mysql -u root -p < Vaultcore.sql
```

## Note

Some parts of this project, including parts of the INSERT data and code, were created with the help of AI. AI was used only to speed up learning, development, and provide examples. The project was reviewed and tested manually.
